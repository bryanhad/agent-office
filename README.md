# Agent Office

A local web app that wraps Claude Code in a visual "office": agents appear as characters at desks on the left, and you chat with them on the right. A personal tool that runs only on macOS, not a product.

**Status: pre-MVP.** Nothing runs yet. See [docs/vision.md](docs/vision.md) for the full picture and [docs/plans/001-mvp.md](docs/plans/001-mvp.md) for what's being built first.
